The launcher

Everything you need. Nothing shouting at you.

OpenClient handles the boring parts carefully: version manifests, libraries, assets, checksums, Java runtimes and sessions. The interface stays out of the way.

01

Verified game files

Mojang's official manifest drives client jars, libraries, natives, assets and the per-OS classpath. Every file is checksum-checked, downloaded in parallel and resumed if interrupted.

02

Microsoft sign-in

Official OAuth device flow for Microsoft, Xbox Live and Minecraft services. Tokens are encrypted with your operating system keychain and refresh silently. Your password never touches OpenClient.

03

One-click profiles

Fabric, Quilt, Forge and NeoForge installs are one action. Each profile keeps its own version, loader, mods, packs, JVM arguments and game directory. Duplicate or repair it at any time.

04

Performance, honestly

Ultra FPS, Balanced and Quality presets resolve version-aware mod sets from Modrinth, install dependencies, tune options.txt and apply JVM flags. No mystery executables.

05

Mods and packs

Browse Modrinth (CurseForge optional) with author and license shown before install. Dependencies are resolved, hashes verified and updates surfaced. Nothing is bundled inside the installer.

06

Logs that help

Live console output, level filters, redacted access tokens, crash report viewer and a repair action that revalidates the client, libraries and assets.

Java Edition

A real launch pipeline, not a shortcut.

OpenClient reads the official Mojang version manifest, merges loader profiles, builds the classpath and arguments with per-OS rules, extracts natives and starts the exact Java major the version needs.

  • Release, snapshot and old version support
  • Fabric, Quilt, Forge and NeoForge
  • Temurin JRE download with SHA-256 verification when Java is missing
  • G1GC, low-latency and ZGC presets with editable arguments
  • Automatic memory recommendation from system memory
  • Offline launch with cached manifests and validated files

Bedrock Edition

Maximum support, without pretending.

Bedrock has no official mod API. OpenClient does everything the platform actually allows and tells you where the line is.

What works

  • Detect and launch the Windows Store / Xbox app install
  • Import .mcpack, .mcaddon, .mcworld and .mctemplate files
  • Manage resource, behavior and skin packs
  • Back up, restore, duplicate, export and import worlds
  • Tune Bedrock graphics options with a backup
  • RakNet server ping, favorites and cross-play tags

What it cannot do

  • Load Java-style client mods
  • Inject code into the game
  • Guarantee a direct join on every Bedrock build
  • Access data folders on consoles or mobile
  • Provide cheats or unfair gameplay advantages

Cross-play aware

Servers carry a Java, Bedrock or Both tag. One click launches the matching edition and pre-fills the address. Cross-play metadata is user-maintained, never guessed.

Security & privacy

Boring in the best way.

No passwords

Microsoft's own pages handle sign-in. OpenClient stores encrypted refresh tokens only.

No telemetry

No analytics, no usage beacons, no third-party tracking. Network calls go to Mojang, Microsoft, Modrinth and CurseForge only.

No injected cheats

Performance and quality-of-life features only. The companion mod is open source and auditable.

Open source

Every line is public. The installer ships no third-party mods; they are downloaded at runtime with author and license shown.

FAQ

Before you install.

Do I need to own Minecraft?

Yes. Java Edition requires a Microsoft account that owns the game. OpenClient verifies ownership through Minecraft services and never asks for your password.

Does OpenClient include mods?

No third-party mods are bundled. Performance and catalog mods are downloaded from Modrinth (and optionally CurseForge) at runtime, with author and license shown.

Can I use it without an account?

The desktop app asks you to sign in before the workspace opens. This keeps sessions and profiles consistent and avoids launching with an invalid identity.

Why does Bedrock have fewer features?

Bedrock has no official client mod API. OpenClient manages the files and settings the platform exposes instead of injecting code or making unsupported promises.

Is the HUD a cheat?

No. It displays information the game already exposes and adds toggle sprint and zoom, which are client quality-of-life features. It contains no combat automation, x-ray or movement exploits.

Which platforms are supported?

Windows is the primary target for the installer and Bedrock support. Linux and macOS builds are supported for Java Edition where its runtime works.
